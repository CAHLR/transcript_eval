# transcript_eval
This repo corresponds to transcript OCR evaluation code featured in the following publication:

Miha Bhaskaran and Zachary A. Pardos. 2025. Automating Academic Transcript Evaluation: A Comparative Study of OCR Techniques for Course and Grade Evaluation. In _Proceedings of the Twelfth ACM Conference on Learning @ Scale_ (L@S '25). Association for Computing Machinery, New York, NY, USA, 366–370. https://doi.org/10.1145/3698205.3733958
